项目初始化向导（模板自带，可整体删除）

- 打开工程时如果没有初始化过会自动弹出；也可以从菜单 Tools > 项目初始化向导 手动打开。
- 窗口里是两个同级设置块，各自带自己的操作行：
  设置块 1：项目初始化
    改 PlayerSettings（产品名 / 公司名 / 包名）、重命名启动场景、替换代码命名空间根，
    点「应用设置」执行，会改写源码并触发重编译。
    包名不能手填：由「公司名」+「产品名」自动组合成 com.{公司名}.{产品名}（只读）。
  设置块 2：远程仓库
    把模板仓库彻底换成自己的新仓库：填 https 地址，可选「完成后立即推送」，确认后
    把当前分支重置成单个初始提交（模板的提交历史不再保留），旧 origin 直接丢弃，
    可选继续执行 git push -u origin <当前分支>。
    只改 .git 内部状态（临时 index + commit-tree + update-ref），不动工作区文件、
    不触发资源重新导入；执行过程在窗口里流式输出，可取消。
    前提：目标仓库已创建且为空、本机能找到 git.exe、凭据可用（HTTPS 会弹 Git 登录窗口）。
    框架子模块保持原样：新仓库 clone 时用 --recurse-submodules。
- 完成标记写在 ProjectSettings/BurnicleProjectSetup.txt（纯文本，记录上次应用的值）；
  删掉该文件后，下次打开工程会重新弹向导。
- 不需要向导时，删除 Assets/BurnicleSetupWizard 整个文件夹即可：
  工程里没有其它代码引用它，删除后不会留下编译错误或其它残留行为。
